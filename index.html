Features

为什么要用它

三行代码换一个 base_url，就能让同一套代码跑遍所有主流大模型平台。

OpenAI 规范兼容

接口完全对齐 OpenAI API 规范。现有的 OpenAI SDK、ChatBox、沉浸式翻译等工具无需改代码，只需替换 base_url。

边缘节点加速

跑在 Cloudflare 全球边缘网络上，请求就近转发。无需自建服务器、无需维护运维，天然具备高可用与低延迟。

密钥不经手服务端

架构为纯转发代理，零环境变量。API Key 由客户端在 Authorization 请求头中携带，Worker 不存储任何密钥。

免费额度充足

Cloudflare Workers 免费套餐每天 10 万次请求。个人日常使用完全够用，无需任何服务器成本。

响应缓存

相同请求体自动命中 Cloudflare 边缘缓存（最长 5 分钟），重复调用不消耗上游配额，显著降低成本与延迟。

路由即选平台

用 URL 路径区分后端：/v2/openai、/v2/groq。多平台并行使用，互不干扰，切换只改一个路径。

Deploy

      
部署你自己的实例

      
全程免费，五分钟搞定。

    


    

      
      

        重要提醒

        *.workers.dev 域名在国内无法直接访问。若要在国内正常使用，需给 Worker 绑定自己的自定义域名。
      

    


    

      

        
1

        

          
Fork 或克隆仓库

          
把代码拿到自己的 GitHub 账号下，作为后续 Cloudflare 部署的来源。

          
git clone https://github.com/zzza123d/llmproxy.git

        

      

      

        
2

        

          
在 Cloudflare 创建 Worker

          
进入 Cloudflare Dashboard → 左侧 Workers & Pages → 切到 Workers 标签 → Create → 连接 Git 仓库。

          
Deploy command: npx wrangler deploy

        

      

      

        
3

        

          
确认关键配置

          
仓库根目录必须存在以下两个文件，否则构建会因找不到入口而失败：

          
wrangler.toml  ← main = "api/llm_api_proxy/index.ts"
package.json

        

      

      

        
4

        

          
绑定自定义域名（国内必做）

          
部署完成后，在 Worker 的 Settings → Domains & Routes 中添加自定义域名。

          
Settings → Domains & Routes → Add → Custom domain

        

      

      

        
5

        

          
验证部署

          
用 curl 请求 /v2/openai 路径测试。注意：根路径 / 返回 404 属正常现象，它是 API 服务而非网页。

          
curl "https://你的域名/v2/openai/v1/chat/completions" \-H "Authorization: Bearer sk-..."
